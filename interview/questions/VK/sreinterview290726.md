3. (продолжение 2) сервис не отвечает по обоим портам, нужно доделать.
Ответ:
sysctl -w net.ipv4.ip_forward=1
iptables -t nat -A PREROUTING -p tcp --dport 8081 -j REDIRECT --to-port 8080
iptables -D INPUT 1
iptables -L INPUT -n
iptables -D INPUT 1
iptables -t nat -A OUTPUT -p tcp --dport 8081 -j REDIRECT --to-port 8080
4. Вывести из лога топ-5 url, возвращающих 404.
Ответ:
grep ' 404 ' nginx_access.log | awk '{print $7}' | sort | uniq -c | sort -nr | head -5
Разбор того, что делает каждая часть (добавленные шаги выделены):
grep ' 404 ' nginx_access.log — выбираем строки с ошибкой 404.
awk '{print $7}' — вырезаем только саму ручку (путь).
sort — сортируем ручки по алфавиту (чтобы одинаковые строки стояли рядом).
uniq -c — (ДОБАВЛЕНО) Считает, сколько раз подряд встретилась каждая строка, и выводит число слева от неё (например: 15 /product/123).
sort -nr — (ДОБАВЛЕНО) Сортирует эти строки по числу повторений в обратном порядке (от большего к меньшему).
head -5 — (ДОБАВЛЕНО) Оставляет только первые 5 строк списка (ваш ТОП-5).
